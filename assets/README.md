# README artwork

The masthead and section rules use a restrained serif treatment coordinated with the paper figures. They are original SVG assets, not journal branding or an indication of acceptance.

The framework, DAT architecture, and motivating example are author-prepared figures from the DRCIM-ML manuscript. The motivating networks are illustrative; their colors do not represent measured activation or robustness gains.

Only these selected figures are included here. The complete manuscript, editable drawing sources, and private reference library are not distributed in this directory.
